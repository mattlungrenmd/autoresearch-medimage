# Website fonts

IBM Plex Sans and IBM Plex Mono are distributed under the SIL Open Font License
1.1. The unmodified Latin WOFF2 subsets are served locally; the page makes no
requests to a third-party font service.

- [IBM Plex project](https://github.com/IBM/plex)
- [Google Fonts: IBM Plex Sans](https://fonts.google.com/specimen/IBM+Plex+Sans)
- [Google Fonts: IBM Plex Mono](https://fonts.google.com/specimen/IBM+Plex+Mono)
- [License](OFL.txt)

The Sans file contains variable weights. Mono uses separate regular and medium
files. These are the Latin subsets supplied by Google Fonts, with system
fallbacks for characters outside the subsets.
