# Website image sources

These images illustrate input types. They are not this project's training data,
evaluation examples, or model outputs. The original JPEG files are redistributed
without pixel edits; the page displays them with CSS crops, dark overlays, and contrast inversion for the OCT crops.

- `chest-xray.jpg`: Mikael Häggström, [Normal posteroanterior chest radiograph](https://commons.wikimedia.org/wiki/File:Normal_posteroanterior_(PA)_chest_radiograph_(X-ray).jpg), [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
- `fundus.jpg`: Ignis, [Fundus of eye normal](https://commons.wikimedia.org/wiki/File:Fundus_of_eye_normal.jpg), [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/). Displayed adaptations retain CC BY-SA 3.0.
- `oct.jpg`: Chan PP, Zhang Y, Pang CP (2023), [Myopic tilted disc: Mechanism, clinical significance, and public health implication](https://doi.org/10.3389/fmed.2023.1094937), *Frontiers in Medicine* 10:1094937, Figure 1. [Wikimedia Commons source](https://commons.wikimedia.org/wiki/File:Fundus_photograph_and_its_corresponding_horizontal_and_vertical_cross-sectional_optical_coherence_tomography_(OCT)_scan.jpg), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

The website's layout and animation direction were inspired by the
[MedVTok project page](https://masaaki-75.github.io/medvtok/). Its research claims,
figures, and animation code are not used here. The diagrams are original and
explain the autoresearch-medimage training and search workflows.
